- Anything else P1 or P2 flagged while reading.

### 3. Data model: decisions to take
| Point | Proposal | Owner affected |
|---|---|---|
| G1 `onDelete` | `Objective → Mission` CASCADE, every other FK RESTRICT; users only suspended | all |
| G3 enums | `varchar` + `CHECK`, no PostgreSQL enums | all |
| G4 uniqueness | unique index on `lower(email)`, `lower(nickname)`, `lower(name)` | P1, P3 |
| MA1 `MissionAccess` | PK `(missionId, userId, source)` so revoking an invitation keeps a manual grant | P1, P3 |
| M3 team sizes | drop `maxTeamSize` (A-19 caps teams at 6) or define it in A-20 | P1 |
| TM1 rejoining a team | surrogate `id` + partial unique `(teamId, userId) WHERE leftAt IS NULL` | P3 |
| P2 A-20 rule | enforced in the service under the mission row lock, not an index | P2 |
| TPE1 `seq` | `max(seq) + 1` under the participation row lock, `UNIQUE (participationId, seq)` | P3 |

The full list (G1–G6, U1–MA1, P1–W1, I1–TPE1) is in #4: points without objections are accepted as proposed.
